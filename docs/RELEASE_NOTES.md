# Ariadne Embroidery Studio 0.1.0

A free, open-source local tool for turning simple artwork into editable embroidery drafts and real PES/DST files.

This first release includes a desktop studio, command line, Python API, editable geometry plans, explicit satin rails, decoded stitch proofs and machine-file audits. Everything runs on your computer after dependencies are installed. No account or paid API is required.

Download the source ZIP or Python wheel and follow the README. New Ariadne code and original geometric examples use the MIT License, so you can use, modify and share them freely.

**Please review and test sew every design.** Automatic image import creates fill drafts; small text and complex artwork still need skilled digitizing. This is not a trained AI model or a machine-certified production digitizer. DST requires the supplied thread chart and machine-specific trim verification.
